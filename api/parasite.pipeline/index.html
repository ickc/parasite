parasite.pipeline module¶

class parasite.pipeline.Config(site_url: str = '', blog_email: str = '', n_jumbotron: int = 1, n_grid: int = 2, index_include_jumbotron: bool = True, tag_cloud_font_size_min: int = 70, tag_cloud_font_size_max: int = 280, logo_url: str = '', show_previewimage_in_post: bool = True, output_dir: Path = PosixPath('output'), date_format: str = '%Y-%m-%d', mathjax_config: str = '', default_lang: str = 'en', root_relative_to_search_form: str = '..', timezone: str = 'America/Los_Angeles', write_tipuesearch_json: bool = True, write_rss: bool = True, write_atom: bool = True, write_sitemap: bool = True, include_draft: bool = False, watch: List[str] = <factory>, watch_open: bool = False, watch_code: bool = False, watch_module: list[str] = <factory>, serve: bool = False, watch_with: str = '', serve_host: str = 'localhost', serve_port: int = 5500, serve_open: Optional[Url] = None)[source]¶

Bases: parasite.live.Config

Configure live serving parameters.

Parameters

  • write_tipuesearch_json – write tipuesearch JSON file.

  • write_rss – write RSS feed.

  • write_atom – write atom feed.

  • write_sitemap – write sitemap.

  • include_draft – output draft posts as well.

  • watch – glob patterns of source files to be watched (relative to current directory)

  • watch_open – if specified, open all pages that are currently watching.

  • watch_code – if specified, open all sources that are currently watching in VSCode.

  • watch_module – if specified, watch & reload this module.

  • serve – if specified, open a server and serve indefinitely.

  • watch_with – valid choices are livereload, watchdog. If not specified, default to livereload if serve, else watchdog.

  • serve_host – the host to serve.

  • serve_port – the port to serve.

  • serve_open – if specified, open this relative url.

Notes

All attributes, properties, and methods must be runtime constant (i.e. not changing after initiated), to ensure caching works properly.

That means methods can only be static methods.

If a method has to depends on self, implement it as a property that returns a callable using closure. See content_footer for an example on how to do this.
