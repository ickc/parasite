    Install

    On PyPI the distribution is pandoc-para for now (the name para is requested); it installs the package para and the command parasite.

    para.site needs Python ≥ 3.12 and pandoc ≥ 3.1. pandoc is not on PyPI: install it from pandoc.org or conda-forge.

    With pixi or conda

    pixi add pandoc
pixi add --pypi pandoc-para

    With pip

    pip install pandoc-para

    Optional parts

    extra for
    pandoc-para[search] search, with Pagefind (its binary comes with it)
    pandoc-para[extras] watching sources and serving the site while you write, reloading pages as they are rebuilt
    pandoc-para[graph] the post graph, with paragraphic

    The check of the output’s links needs lychee (pixi add lychee; see builds).

    Filters a site uses (pantable, pannb, …) are installed like any package, then named in its parasite.toml (see filters).

    From the source

    git clone https://github.com/ickc/parasite
cd parasite
pixi run test
