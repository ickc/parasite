# parasite's default theme

The style sheets the default `[minify.css]` bundles, used when a site has no copy of its
own under `_css/`. They come from Nikola's bootblog4 theme, as parasite's sites have
carried them:

- `bootstrap.css`: Bootstrap 4 (MIT);
- `rst_base.css`: docutils' base style sheet, by Günter Milde (BSD-2-Clause);
- `nikola_rst.css`, `code.css`, `theme.css`, `bootblog.css`: Nikola's (MIT);
- `custom.css`: the sites' additions.
